# Technology icon sources

This portfolio uses local SVGs to represent software and technologies.

- **Devicon** (https://github.com/devicons/devicon): dotnetcore.svg, visualbasic.svg, html.svg, css.svg, entityframework.svg, postman.svg, azuredevops.svg, express.svg, flask.svg and cosmos.svg. Devicon's MIT license is reproduced in `DEVICON-LICENSE.txt`. Previously included Devicon artwork is also used throughout the site.
- **NSubstitute** (https://github.com/nsubstitute/nsubstitute.github.com/blob/master/logo.svg): nsubstitute.svg (SVG header/metadata removed for embedding).
- **Simple Icons / Garmin** (https://github.com/simple-icons/simple-icons/blob/develop/icons/garmin.svg): garmin.svg.
- **Original generic symbols**: api.svg (network/API integration) and nunit.svg (test checklist). These are illustrative icons, **not official brand logos**.

Brand marks are shown for identification only; their use does not imply endorsement by their owners.
